## 🚀 Проекты

### 📊 [CoreCRM — Enterprise Kanban Board](https://crm-dashboard-mu-nine.vercel.app/)
Интерактивная b2b-система управления задачами и спринтами для команд разработки, симулирующая реальное enterprise-окружение.
* **Стек:** React 18, TypeScript, Zustand, `@hello-pangea/dnd`, Tailwind CSS, Vite.
* **Архитектура:** Проведен глубокий рефакторинг с избавлением от паттерна *God Component*. Логика разделена на изолированные модули: `BoardMetrics` (аналитика KPI спринта), `TaskForm` (инкапсулированная форма с обработкой `Escape`), `BoardFooter` (b2b-документация) и чистый оркестратор `Board`.
* **Функционал:** Настоящий коммерческий интерфейс, живой подсчет метрик выполнения задач, интерактивные разделы со спецификацией REST API (cURL примеры) и статусом микросервисной инфраструктуры, сквозной Dark Mode и полная адаптивность (мобильные табы).


### 🔍 [Github Explorer](https://git-hub-explorer-beta.vercel.app/)
Приложение для поиска GitHub-пользователей и просмотра их репозиториев.
- Стек: React, TypeScript, Vite
- Поиск GitHub-пользователей с debounce
- Карточка профиля: аватар, bio, статистика, ссылки
– Список репозиториев с фильтрацией по языку и сортировкой по звёздам / дате / имени
– Скелетон-лоадеры и обработка ошибок (404)
– Кастомные хуки: useGithub, useDebounce
